# 血液検査week 素材メモ（全8回・毎日18時の別枠）

作成：2026-10-11 ／ 用途：120歳まで歩くラボ 自動投稿の18時の枠（イレギュラー発信）
このメモは投稿を作るための「素材」です。**血液検査は、診断・治療の判断に見える書き方を絶対にしない**こと。

## 決まりごと
- ビタミンweekと同じ18時の枠。カテゴリーは「血液検査」（色は黄色、ラベルは「血液検査」）
- 表紙のかいたろ君は assets/character-special.png（イレギュラー発信のルールどおり）
- 表紙に「血液検査week 1/8」のようにシリーズ名と番号を入れる
- 投稿日：ビタミンweek（〜10/24）の翌日から、**10/25（日）〜11/1（日）の8日間**

## 書き方のルール（特に大事）
- 数値は、厚生労働省「標準的な健診・保健指導プログラム（令和6年度版）」の**保健指導判定値・受診勧奨判定値**として紹介する
  - 「この数値なら○○病」とは書かない。「生活習慣を見直す目安」「医療機関の受診をすすめられる目安」という言い方にする
  - 「健診機関によって基準範囲が少し違うことがあります」と入れる
- 毎回、最後に次の2つを入れる
  - 「健診で受診をすすめられたら、早めに医療機関へ」
  - 「治療中の方は、数値の見方を主治医にご相談ください」
- 1つの数値だけで判断しないこと、前年と比べる（経年変化を見る）ことの大切さを伝える
- 薬・サプリで数値を下げる話はしない。生活のポイントは、厚労省 e-ヘルスネット等で確かめられた範囲だけ書く
- 参考：厚生労働省「標準的な健診・保健指導プログラム（令和6年度版）」、厚生労働省 e-ヘルスネット ほか
- 最終回の最後に「120歳まで健康アプリで、毎日の記録を続けましょう」と一言

## 各回のメモ
### 1/8 HbA1c（＋空腹時血糖）
- **わかること**：赤血球のヘモグロビンにブドウ糖がくっついた割合。過去1〜2か月の血糖の平均的な状態がわかる。空腹時血糖は「その時」の値
- **ポイント**：検査前日の食事の影響を受けにくい
- **生活のポイント**：e-ヘルスネットで確かめられた範囲（食事・運動）で書く

### 2/8 LDLコレステロール
- **わかること**：血液中のコレステロールのうち、増えすぎると血管の壁にたまりやすいもの（いわゆる悪玉）
- **ポイント**：高い状態が続くと、動脈硬化の原因の1つになる

### 3/8 HDLコレステロール
- **わかること**：余分なコレステロールを回収するはたらきのもの（いわゆる善玉）
- **ポイント**：ほかの項目と違い、**低いほう**に注意（40未満が保健指導判定値）

### 4/8 中性脂肪
- **わかること**：体のエネルギー源になる脂肪。余ると体脂肪としてたまる
- **ポイント**：食事やお酒の影響を受けやすい。令和6年度から、食後（随時）の目安175も設けられた

### 5/8 AST・ALT
- **わかること**：肝臓などの細胞に含まれる酵素。細胞がこわれると血液中に増える
- **ポイント**：ALTは主に肝臓に多い。ASTは肝臓のほか筋肉などにも含まれる（激しい運動の後に上がることがある）

### 6/8 γ-GT（γ-GTP）
- **わかること**：肝臓や胆道の状態を反映する酵素
- **ポイント**：お酒の飲みすぎで上がりやすいことがよく知られている。お酒以外の原因で上がることもある

### 7/8 eGFR
- **わかること**：腎臓が血液をろ過する力の目安。血清クレアチニンの値と年齢・性別から計算する
- **ポイント**：年齢とともに下がりやすい。尿検査（尿たんぱく）とあわせて見ることが大切

### 8/8 ヘモグロビン（最終回）
- **わかること**：赤血球の中で酸素を運ぶたんぱく質。少ないと貧血
- **ポイント**：男女で目安が違う。ビタミンweekのB12・葉酸、鉄の話とつなげる
- **まとめ**：8回をふり返り、「1つの数値で一喜一憂せず、毎年の変化を見る」「受診をすすめられたら早めに」で締める
