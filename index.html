このラボについて

経験10年の理学療法士が、からだと暮らしの健康情報をやさしい言葉で発信しています。

介護をしている方・介護を受けている方・介護職の方に向けて、次のような内容をお届けしています。

  • 体操・ストレッチなど、体を動かすヒント
  • 体のしくみや、病気の予防についての知識
  • 転ばない環境づくりなど、暮らしの心がけ

内容は、厚生労働省などの公的機関や学会の資料にもとづいて作っています。

YouTube への投稿について

Instagram と同じ内容の短い動画を、運営者自身の YouTube チャンネルにも投稿しています。投稿には、運営者が自分のチャンネル専用に使うアプリ「120lab-youtube」（YouTube API サービスを利用）を使っています。
