プライバシーポリシー

制定日：2026年10月2日

1. このポリシーの対象

このポリシーは、「120歳まで歩くラボ」の運営者（以下「運営者」）が使うアプリ「120lab-youtube」（以下「本アプリ」）での情報の取り扱いについて定めたものです。

2. 本アプリの目的

本アプリは、運営者が自分の YouTube チャンネルに、自分で作った動画をアップロードするためだけに使います。運営者以外の人が使うことはなく、ほかの人の YouTube アカウントにアクセスすることもありません。

3. 集める情報・使い方

  • 本アプリは、運営者以外の人の個人情報を集めません。保存もしません。
  • 本アプリが使う Google の認証情報は、運営者自身のアカウントのものだけです。動画のアップロード（youtube.upload）にだけ使い、安全な場所に保管しています。
  • 集めた情報を第三者に提供・販売することはありません。

4. YouTube API サービスの利用

本アプリは YouTube API サービスを利用しています。本アプリを通じて YouTube を利用する場合は、次の規約・ポリシーが適用されます。

  • YouTube 利用規約（https://www.youtube.com/t/terms）
  • Google プライバシーポリシー（https://policies.google.com/privacy）

本アプリへのアクセス許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。
